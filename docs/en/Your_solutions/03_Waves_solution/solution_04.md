# 🌊 Phase Difference — Step-by-Step Solution

## 📘 Problem

What is the **phase difference (in radians)** between two points on a wave that are separated by:

```
λ / 3
```

---

# 🧠 Step 1 — Understand the Concept

A full wavelength corresponds to a full phase:

$$
\lambda \longleftrightarrow 2\pi \text{ radians}
$$

👉 This means:

- 1 wavelength = $2\pi$ radians  
- Any fraction of wavelength gives proportional phase  

---

# ⚡ Step 2 — Use the Formula

Phase difference formula:

$$
\Delta \phi = \frac{2\pi}{\lambda} \cdot \Delta x
$$

Where:

- $\Delta x$ = distance between points  
- $\lambda$ = wavelength  

---

# 🧮 Step 3 — Substitute Values

Given:

$$
\Delta x = \frac{\lambda}{3}
$$

Substitute:

$$
\Delta \phi = \frac{2\pi}{\lambda} \cdot \frac{\lambda}{3}
$$

---

# ✂️ Step 4 — Simplify

Cancel $\lambda$:

$$
\Delta \phi = \frac{2\pi}{3}
$$

---

# ✅ Final Answer

$$
\Delta \phi = \frac{2\pi}{3} \text{ radians}
$$

---

# 🎓 Key Idea

```
Phase ∝ distance along the wave
```

So:

- half wavelength → $\pi$  
- quarter wavelength → $\frac{\pi}{2}$  
- one third → $\frac{2\pi}{3}$  

---

# 📊 Quick Reference

| Distance | Phase difference |
|---------|----------------|
| λ | $2\pi$ |
| λ/2 | $\pi$ |
| λ/3 | $2\pi/3$ |
| λ/4 | $\pi/2$ |

---

# 🏁 Final Insight

```
Phase difference = fraction of wavelength × 2π
```
