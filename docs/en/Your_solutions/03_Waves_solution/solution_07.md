# 🌊 Standing Wave on a String – Step-by-Step Solution

A standing wave with **four antinodes** is produced on a string of length:

L = 80 cm

We need to determine:

### a) The wavelength λ

---

# 📘 Step 1: Understand Standing Waves on a String

For a string fixed at both ends:

- **Nodes** occur at the ends
- Each **antinode** represents one loop
- Each loop has length:

λ / 2

So if there are **n antinodes**, then:

L = n × (λ / 2)

---

# 📘 Step 2: Insert Given Values

We are told:

- Number of antinodes = 4
- Length of string = 80 cm

So:

80 = 4 × (λ / 2)

---

# 📘 Step 3: Simplify

80 = 2λ

Now divide both sides by 2:

λ = 40 cm

---

# ✅ Final Answer

**λ = 40 cm**

or in meters:

**λ = 0.40 m**

---

# 📌 Final Summary

| Quantity | Value |
|--------|-------|
| String Length | 80 cm |
| Number of Antinodes | 4 |
| Wavelength | 40 cm |

---

# 🧠 Extra Note

For a string fixed at both ends:

L = nλ / 2

where:

- L = string length  
- n = number of antinodes  
- λ = wavelength
