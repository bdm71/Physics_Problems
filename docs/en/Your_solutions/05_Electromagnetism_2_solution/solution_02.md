# Magnetic Field Between Two Parallel Wires

## Given
- Distance between the wires:  
  `d = 10 cm = 0.10 m`

- Current in each wire:  
  `I = 5 A`

- Currents flow in opposite directions.

- We need to find the magnetic field at the midpoint between the wires.

---

# Step 1: Find the distance from the midpoint to one wire

Since the point is exactly halfway between the wires:

```math
r = d / 2
```

```math
r = 0.10 / 2 = 0.05 \text{ m}
```

---

# Step 2: Use the magnetic field formula

The magnetic field produced by a long straight wire is:

```math
B = \frac{\mu_0 I}{2\pi r}
```

Where:
- `μ₀ = 4π × 10⁻⁷ T·m/A`
- `I = 5 A`
- `r = 0.05 m`

---

# Step 3: Calculate the magnetic field from one wire

Substitute the values into the formula:

```math
B_1 = \frac{(4\pi \times 10^{-7})(5)}{2\pi(0.05)}
```

Simplify:

```math
B_1 = \frac{20\pi \times 10^{-7}}{0.1\pi}
```

```math
B_1 = 2 \times 10^{-5} \text{ T}
```

---

# Step 4: Find the total magnetic field

The currents are in opposite directions, so the magnetic fields at the midpoint point in the same direction and add together:

```math
B_{\text{total}} = B_1 + B_1
```

```math
B_{\text{total}} = 2(2 \times 10^{-5})
```

```math
B_{\text{total}} = 4 \times 10^{-5} \text{ T}
```

---

# Final Answer

```math
\boxed{4 \times 10^{-5} \text{ T}}
```

### Direction
Using the right-hand rule, the magnetic field at the midpoint is in the same direction for both wires:
- Into the page (if the left wire current is upward and the right wire current is downward).
